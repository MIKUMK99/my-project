## 图片路径规则（重要）

md 文件在 `md文件\` 里，图片在上一层的 `photos\`，所以路径必须写成：

```md
![说明](../photos/点开主界面.png)
```

三条规则：

1. **相对路径**，不要用 `D:\...` 绝对路径。绝对路径在导出 PDF 时会变成空框。
2. **正斜杠 `/`**，不能用反斜杠。`\` 在 Markdown 里是转义符。
3. **不要加引号**，`](path)` 里直接写路径。

**以后如果再移动 md 文件的位置，所有图片路径都要跟着改。** 这是这个项目踩过的坑。

## 数据从哪来

```text
数据清洗表格\清洗过后.csv
        ↓  python scripts/csv_to_data_js.py 数据清洗表格\清洗过后.csv --date=2026-10-20
原型\data.js
        ↓
六个页面（数字全部由 data.js 计算，不写死）
```

**改了数据就重跑一次脚本，不要手改 `data.js`。** 手改过一次，以后就说不清页面上那个数是从哪来的。

## 三个数怎么验证

```text
Excel 筛选     →  1000 / 420 / 334
SQL 查询       →  python scripts/run_sql.py 数据清洗表格\清洗过后.csv
Python 脚本    →  结果同上
```

三种方式结果一致，数字才算数。

## 导出 PDF 的设置

```text
纸张：A4      方向：纵向      边距：2cm
```

截图是 1920×911，比例 2.11，直接放进 A4 纵向字会很小。**建议先把左右空白裁掉**，裁到 1040 左右，字大一倍。

导出后检查四件事：图片有没有空框、字能不能看清、表格有没有被拦腰截断、目录页码对不对。

## 一条规矩

`03_取舍.md` 是这份作品里唯一不能抄的部分。改它之前，先想清楚「放弃了什么、为什么、代价是什么」——三样缺一样，那一条就不算写完。
